# Kerex Install Configs

Community-contributed install packages for [Kerex](https://kerex.app). Each config defines a step-by-step installer that runs on any GitHub repository.

## Browse & Install

Visit [install.kerex.app](https://install.kerex.app) to browse and install packages.

## Create a Package

Use the [visual editor](https://install.kerex.app/editor) to design your install package, or see [CONTRIBUTING.md](CONTRIBUTING.md) for manual creation.

## Validation

```bash
npm ci
npm run validate
```
